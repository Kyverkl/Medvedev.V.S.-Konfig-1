# Эмулятор командной оболочки (вариант 18)

GUI-эмулятор командной строки UNIX-подобной ОС на PyQt6.

## Запуск

```bash
uv run repl [--vfs ПУТЬ] [--script ПУТЬ]
```

- `--vfs` — путь к физическому расположению VFS
- `--script` — стартовый скрипт; комментарии начинаются с `#`

Примеры запуска — в `scripts/`, стартовые скрипты — в `startup/`, тестовые VFS — в `vfs/`.

## Команды

| Команда | Описание |
|---|---|
| `ls [-l] [путь...]` | содержимое каталогов |
| `cd [путь]` | смена текущего каталога |
| `cat файл...` | вывод содержимого файлов |
| `wc [-l] [-w] [-c] файл...` | число строк, слов и байт |
| `cal [[месяц] год]` | календарь |
| `chmod режим путь...` | права доступа (`755`, `u+x`, `go-w`, `a=r`), только в памяти |
| `vfs-init` | VFS по умолчанию с очисткой физического каталога |
| `help [команда]` | справка |
| `exit` | выход |

Новая команда — модуль в `src/repl/commands/` с наследником `Command` и строка в `all_commands()`.

## VFS

VFS загружается из каталога на диске целиком в память; все изменения происходят только в памяти.
Исключение — служебная команда `vfs-init`: она заменяет VFS на пустую и **очищает физический каталог**,
поэтому скрипты в `scripts/` работают с временной копией.

## Структура

- `src/repl/config.py` — параметры командной строки
- `src/repl/gui.py` — окно (вывод + строка ввода)
- `src/repl/shell.py` — состояние оболочки и выполнение команд
- `src/repl/vfs.py` — VFS в памяти и её загрузка
- `src/repl/parser.py` — разбор строки на команду и аргументы
- `src/repl/commands/` — команды, по одной на модуль; регистрация в `commands/__init__.py`
